## [Three.js](https://threejs.org/)

*2026-06-11 · UI, 3D*

Créer des scènes 3D interactives dans le navigateur, avec cette bibliothèque JavaScript qui s'appuie sur WebGL et WebGPU.

## [CVA, Class Variance Authority](https://cva.style/)

*2026-06-09 · Design system*

Déclarer les variantes d'un composant de façon typée, au-dessus de Tailwind ; shadcn/ui s'en sert.

## [Impeccable style](https://impeccable.style/)

*2026-02-01 · IA, UI*

Obtenir d'une IA qui code des interfaces moins génériques, grâce à 24 commandes à glisser dans le prompt.

## [Untitled UI](https://www.untitledui.com/react)

*2025-07-17 · Design system, UI*

Copier-coller un design system entier, fichier Figma et composants React/Tailwind compris.

## [coss ui, ex-Origin UI](https://coss.com/ui)

*2025-06-11 · UI*

Puiser des composants React/Tailwind à copier-coller dans l'esprit de shadcn/ui avec coss ui, la suite d'Origin UI depuis son rachat par Cal.com, désormais construite sur Base UI. Les centaines de composants d'origine restent consultables sur [coss.com/origin](https://coss.com/origin).

## [21st](https://21st.dev/)

*2025-06-11 · UI*

Trouver des composants React (shadcn) prêts à intégrer, sur une place de marché alimentée par la communauté.
